# Fonts

Spec 018 (Triangulación). Static TTF instances from Google Fonts, both under the SIL Open Font License 1.1
(https://openfontlicense.org). The license and copyright notice must accompany redistributions of the font files
(e.g. in the app's open-source licenses screen).

- **Bricolage Grotesque** (Medium 500, SemiBold 600, Bold 700, ExtraBold 800), by Mathieu Triay: display, titles and
  figures (`stat-xl`, `display-*`, `title`).
- **Instrument Sans** (Regular 400, Medium 500, SemiBold 600, Bold 700), by Instrument: text and UI (`body*`, `label*`).
